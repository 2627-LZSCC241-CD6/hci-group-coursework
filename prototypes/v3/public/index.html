One Step at a Time

Follow a computer maintenance procedure using either a Manual or an Interactive guide.

  1. Choose a procedure below.
  2. Select Manual or Interactive guide, then press Start.
  3. Read the instructions on the left and click the parts in the hardware photo on the right.
  4. Use Pause to take a break, or End run to stop. Return here when your run is finished.

Logs stay available while this page remains open. Export them before refreshing or closing the page.
